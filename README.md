# JARVIS — Python AI Chatbot

A simple **Jarvis-style AI chatbot** built with Python and powered by the **Grok API**.

You can chat with Jarvis directly from your terminal. The project is intentionally simple — just add your API key and start chatting.

## Features

* AI chatbot powered by Grok
* Simple terminal-based interface
* Built with Python
* Easy API key setup
* Requires an internet connection
* Only one main Python file

## Requirements

* Python 3.10 or newer
* Internet connection
* Grok API key

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Open the project folder:

```bash
cd YOUR-REPOSITORY
```

Install the required package:

```bash
pip install openai
```

## Add Your API Key

Open `main.py`.

Find the API key section and add your Grok API key:

```python
API_KEY = "YOUR_GROK_API_KEY"
```

Replace `YOUR_GROK_API_KEY` with your actual API key.

**Important:** Never upload your real API key to GitHub. Keep it private.

## Run Jarvis

Start the chatbot with:

```bash
python main.py
```

That's it.

Once it starts, you can type your messages and chat with Jarvis.
